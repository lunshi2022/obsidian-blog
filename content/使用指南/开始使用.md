这套站点只有一个原则：**你只管在 Obsidian 里写 Markdown，剩下的交给自动流程。**

## 三种发布方式

1. **一键部署器（Windows，首次用）**：到 [Releases](https://github.com/lunshi2022/obsidian-blog/releases) 下载 `GardenDeployer.exe`，填好目录、仓库名、令牌，它会自动装环境、建仓库、发布站点
2. **Obsidian 插件（日常用）**：写好笔记，点左侧 ↑ 图标（或右键笔记「上传到博客」），插件自动复制笔记与附件、构建、推送。约 1–3 分钟后网站自动更新
3. **手动**：`git add -A && git commit -m "更新笔记" && git push`，GitHub 云端自动构建

> [!tip] 上传前先保存
> 插件读取的是磁盘上的文件，Obsidian 里没保存的改动不会被上传——按一次 `Ctrl+S` 即可。

## 站点配置

根目录的 `site.config.json` 控制全站的名称、配色和署名：

```json
{
  "title": "我的数字花园",
  "mark": "◈",
  "description": "这里是一句话介绍",
  "author": "你的名字",
  "siteUrl": "https://你的用户名.github.io/仓库名/",
  "theme": "garden",
  "repo": "https://github.com/你的用户名/仓库名"
}
```

| 字段 | 作用 |
| --- | --- |
| `title` | 左上角品牌名、首页大标题、浏览器标签页标题 |
| `mark` | 左上角图标里的字符，任意一个字符或 emoji |
| `description` | 首页副标题，也用于搜索摘要 |
| `author` | 页脚版权署名 |
| `theme` | 配色：`garden` 青绿 / `ink` 墨蓝 / `dawn` 暖阳 |
| `repo` | 页脚 GitHub 链接，留空则不显示 |

`siteUrl` 只影响 RSS 里的绝对链接，不填也能正常部署。

## 本地预览（可选）

装了 Node.js 的话，Obsidian 命令面板 →「本地预览（构建并打开浏览器）」，默认开在 `http://localhost:4321`；看完执行「停止本地预览服务」。也可以在终端里跑 `npm run dev`。

没装 Node 完全不影响发布——站点由 GitHub Actions 在云端构建。

## 目录结构

```
content/           你的笔记（index.md 是首页）
content/使用指南/   这几篇示例文档，看完可以直接删
content/附件/       图片、PDF 等附件
assets/style.css   配色与字体（改 CSS 变量即可换装）
src/               构建脚本，一般不用动
```

## 什么时候需要改代码

基本不用。真想改的话：

- **配色字体**：`assets/style.css` 顶部的 CSS 变量
- **页面结构**：`src/lib/templates.js`
- **解析规则**：`src/lib/markdown.js` 和 `src/lib/obsidian.js`
