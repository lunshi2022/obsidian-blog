除了标准 Markdown，这里支持 Obsidian 的常用扩展语法。下面每一条都在实际渲染，你可以直接对照源码看效果。

## 标题

`#` 到 `######` 六级，会自动生成锚点并出现在右侧目录。**笔记开头如果写了和标题重复的一级标题，会被自动去掉**，避免页面上出现两个大标题。

## 文字

**加粗**、*斜体*、~~删除线~~、`行内代码`、==高亮==。

组合也支持：***又粗又斜***。

## 列表

无序列表：

- 第一项
- 第二项
  - 嵌套一层
  - 再嵌一层
- 第三项

有序列表：

1. 先做这个
2. 再做那个
3. 最后收尾

任务列表：

- [x] 搭好骨架
- [x] 写示例笔记
- [ ] 换成自己的内容
- [ ] 绑上自己的域名

## 代码块

```js
function greet(name) {
  return `你好，${name}。`;
}

console.log(greet('世界'));
```

代码块右上角有复制按钮，鼠标移上去才会出现。

## 引用与 Callout

普通引用：

> 引用是一段被隔离出来的文字，用来强调来源或语气。

Callout 有类型和图标：

> [!tip] 小技巧
> 在 Callout 标记后面加 `-` 可以让它默认折叠，比如 `> [!note]- 点我展开`。

> [!note]- 默认折叠的 Callout
> 你现在看到的是展开后的内容。这种写法适合放补充材料，不打断正文。

> [!danger] 注意
> 删除笔记前记得确认它没有被别的笔记引用。

支持的类型：`note` `info` `tip` `success` `warning` `danger` `example` `question` `quote` `todo` `bug` 等等。
